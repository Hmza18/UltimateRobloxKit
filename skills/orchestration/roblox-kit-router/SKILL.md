# UltimateRobloxKit router

Load as little as possible. Read this table, pick the workflow, then open only the listed skills. Open a skill's `references/` files only when its body tells you to.

## When to use

- The task spans more than one area (code plus assets plus UI), or you are not sure which skill fits.
- Not for a single obvious question: go straight to that skill.

## Workflow

1. Classify the request. Run the deterministic twin if a shell is available:
   `python3 $URK/scripts/automation/route.py "<the user's request>"`
   It prints the matched workflow, the skills in load order and the validation gates. Treat it as a strong suggestion, then use judgement.
2. Read `kit-conventions` once per session. It holds the stop rules and checkpoints every workflow shares.
3. Read the primary skills for the current step only. Defer the rest until their step starts.
4. Split independent steps (for example "server data layer" and "HUD") into parallel subagents when the agent supports it, each given only its own skills.
5. Close every step with its gate. Do not move on while a gate fails; after three failed fix attempts on one issue, stop and report it.

## Workflow recipes

Defined in `$URK/catalog/workflows.json`. Summary:

| Workflow | Use for | Core skills |
|---|---|---|
| new-game | "build a simulator / tycoon / obby / RPG" | game-design-core, roblox-architecture, roblox-toolchain-doctor, roblox-data-persistence, roblox-networking, roblox-ui-systems, roblox-testing-debugging, roblox-publishing-liveops |
| gameplay-system | one feature: inventory, shop, quests, NPCs | roblox-architecture, roblox-networking, roblox-security-anti-exploit plus the feature skill |

| environment | maps, terrain, lighting, buildings | map-world-building, lighting-atmosphere, modular-buildings-props, roblox-performance |
| ui | HUD, menus, shop screens | roblox-ui-systems, game-art-presentation |
| character | creatures, rigs, animation | characters-rigging, roblox-animation, blender-roblox-export |
| release | publish, update, live ops | roblox-publishing-liveops, production-management, roblox-security-anti-exploit |

## Example

"Create 20 supermarket products" → `asset-batch`, plus `product-packaging-assets` from its triggers. Steps: spec file → `scripts/export/asset_batch.py` in batches of five → look at the contact sheet → stop for the user's approval → `package_batch.py --license N` into `handoff/License<N>` → next batch. Size new objects from `license-folder-delivery`'s approved references.

## Limitations

- Activation inside Claude Code depends on each skill's description; this router and `route.py` improve the odds but cannot force it.
- The router knows only installed kit skills. Third-party skills fetched with `scripts/install/third_party.py` are not routed.
