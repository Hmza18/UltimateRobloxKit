# Icon licences

## URK Icons (`assets/icons/urk/`)

You may use them in commercial Roblox games, modify them and redistribute them. Attribution is appreciated but not required beyond keeping the repository licence with redistributed copies of the source files.

## Third-party packs

No third-party icons are stored in this repository. Packs that allow use in a game but not republication (for example the BuiltByBit "Free Icon Pack", resource 54420, whose licence could not be verified because builtbybit.com blocks automated access) can be converted locally with `tools/icons/import_pack.py`. It records the source and the licence you accepted in `PROVENANCE.md`, and writes a `.gitignore` so the files are not committed by accident.

Redistributable alternatives worth importing the same way (check each licence yourself): Kenney "Game Icons" (CC0), game-icons.net (CC BY 3.0, credit required), Lucide (ISC), Tabler Icons (MIT), Phosphor (MIT). Export SVG sets to PNG first.
